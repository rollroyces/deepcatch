Quickstart

Five lines to a panel-based MRD score on real TCGA tumor mutations.

git clone https://github.com/rollroyces/deepcatch.git
cd deepcatch && python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"      # [dev] adds pytest; the base install does not
pytest -q                     # 1040 tests (the deep-learning ones skip
                              #   without the [api] extra)
bash RUN_ALL.sh --quick      # the validation run, into a scratch directory

Validated end-to-end on real TCGA-LUAD mutations (GDC, open access) and FLARE/GSE317007 real cfDNA.

Two complementary channels

DeepCatch ships two detection channels that are individually useful and even better together:

Mutation-informed (this repo)

Per-locus Poisson LLR aggregation across tumor-suppressor panel. Best at MRD-style ultra-low VAF (≤0.1%). Trained on real TCGA-LUAD mutations with a context-aware sequencing error model.

AUC 0.921 at 0.1% ctDNA on 20 TCGA-LUAD patients.

Tumor-naive fragmentomics

5-mer end motifs + fragment size distribution + DELFI/WPS coverage profiles. No tumor mutations required. Best at pan-cancer screening.

AUC 0.9684 ± 0.0027 on 627 cross-study samples from FinaleDB (GC-corrected; legacy no-GC baseline 0.9770 ± 0.0013). 0.9444 [0.8731–1.0000] on a held-out publication that contributes no training data, 0.708 on a second, 0.7385 pooled.

Fusion (naive average)

Two channels averaged. AUC 0.9884 — paired over 10 seeds: +0.0144, t = 54.50, positive on every seed. The mutation channel in this pairing is a calibrated synthetic proxy (AUC 0.902), so it is a complementarity result, not a performance claim.

Per-sample risk score

Standalone cfdna-score CLI scores any sample against the trained model in <1 s with cache hit. SCORE_USAGE.md →

Tissue-of-origin

6-class TOO from fragmentomics alone: macro AUC 0.9533 (full), 0.9338 within-Cristiano (batch-effect removed). Top-1 79.4%, top-2 90.7%. These four figures come from an archived experiment (91a95b0) whose input and output are not in this repository, so they can be read but not recomputed here — the deconvolution model that produced them is not committed either.

Methylation channel (separate repo)

FinaleMe runs end-to-end on real public fragment files here, and the channel was measured and reported as a null: its AUC equals the library-depth baseline exactly, and at the 103,863 loci where both arms have coverage the median cancer-vs-control difference is 0.0 (permutation p = 1.0). The cause is measured too — the public libraries are size-selected at ~300 bp and deliver ~1 observation per CpG. write-up →

Read the held-out rows as a late-stage transfer result. Where the public records characterise them, the held-out cohorts are advanced-stage: Snyder 2016 is Stage IV throughout (per its own GEO extract protocol) and Adalsteinsson 2017 is a metastatic cohort. No case in the held-out cohort is placed at Stage I by the records that were read, so these AUCs say nothing about early detection — see EXTERNAL_VALIDATION.md.

Five more external cohorts, and what each one settles. The ccRCC cohort is a second external family — the ranking transfers (0.9444, exact permutation p = 0.0043) — and it comes with a disclosed confound: sequencing depth alone separates its two arms at 0.8333, so the number is quoted with that baseline next to it (the model's separation survives it, 0.9722 with the depth removed). SAUNA is the cohort with a graded label: nine colorectal plasma samples, each carrying a per-sample tumour fraction, and the tumour-naive score tracks that fraction (Spearman rho 0.8154 within the seven CRC samples, p = 0.0355; the short/long ratio carries more of it, 0.9643), with the one patient sampled three times rising with it. The Cleveland Clinic PHTS cohort is a hereditary-cancer screening population whose malignant samples are mostly subclinical — nothing separates there, not even a model fitted and cross-validated inside the cohort (0.5465) — so that one is a statement about the cohort, not about the model. And the immunotherapy cohort is the one whose endpoint is a treatment response rather than a cancer/healthy contrast (184 longitudinal plasma samples from 68 patients across six centres): the study's own metric finds 0 of 5,527 bins differential where the paper reports 1,080, and the classifier reaches 0.3373 — while the same features separate two collection centres that share a response label at 0.9813, so the cohort's structure is the centre, not the response. The end-motif cohort is the one whose class AUCs look strongest — 0.8207 on the published CC-/CA-end statistic, permutation p = 5e-05 — and cannot be read as a class signal: the same 256 features separate two cancer groups from different studies at 0.9996, so the study structure in these libraries is larger than any class effect here. Every number on this page is in a committed JSON artifact — results/external_cohort_zenodo_ccrcc.json, results/external_cohort_zenodo_sauna.json, results/external_cohort_zenodo_phts.json, results/external_cohort_zenodo_endmotif.json and results/external_cohort_zenodo_immunotherapy.json — and the per-cohort write-ups are in PUBLIC_DATA_SOURCES.md.
