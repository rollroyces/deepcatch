# DeepCatch Python Validation Results

Generated by `validation/py/run_all.py`.

## Output Files

### `real_downsampled.json`
Realistic cfDNA downsampling with 6 literature-parameterized confounders.
- **Supports claim**: "Realistic noise applied" (Section 2 of report)
- **Size**: Large (contains all observation-level data)
- **Structure**: `metadata`, `per_fraction_stats`, `observations` by ctDNA fraction

### `head_to_head_results.json`
Head-to-head comparison of DeepCatch vs Bie et al. (2023) on same data/same folds.
- **Supports claim**: Head-to-head results table (Section 3 of report)
- **Contains**: Summary table, per-fraction AUC with bootstrap CIs, DeLong test results
- **Key metric**: `detection_limit_ctdna_fraction` — lowest ctDNA with AUC>0.80

### `cet_results.json`
Cumulative Evidence Tracking (SPRT) with Gompertz growth model.
- **Supports claim**: CET performance (Section 4 of report)
- **Contains**: Sensitivity, specificity, AUC, per-cancer breakdown, ROC curve
- **Key targets**: sens≥70% + spec≥95% (verdict in `targets.both_met`)

### `too_results.json`
Tissue-of-Origin multi-class prediction on simulated methylation + fragmentomics.
- **Supports claim**: TOO accuracy (Section 5/6 of report)
- **⚠️ Caveat**: Simulation ONLY — not comparable to Grail clinical 88.7%

### `clinical_comparison.json`
Honest comparison between DeepCatch (simulation) and published clinical assays.
- **Supports claim**: Published comparison table (Section 5 of report)
- **Contains**: Summary table, detailed comparisons with caveats, honest assessment

## Reproducibility

- **Random seed**: 42 (all runs)
- **Cross-validation**: 5-fold stratified (3-fold in demo mode)
- **Bootstrap**: 2,000 iterations (200 in demo mode)
- **DeLong test**: Two-sided, α = 0.05
- **Gompertz parameters**: From Friberg 2013, Mehrara 2007
- **ctDNA shedding**: From Bettegowda 2014, Chabon 2020

## Running

```bash
cd cancer-screening
python -m validation.py.run_all          # Full run (~10-30 min)
python -m validation.py.run_all --demo    # Demo (~2 min)
python -m validation.py.run_all --phase 3 # Head-to-head only
```

## Important Caveats

**ALL DeepCatch results are simulation-based.** No clinical validation has been
performed. Direct comparison to clinical assays (Guardant360, Grail Galleri, etc.)
is NOT scientifically valid — it is provided for context only.

For publication, wet-lab validation on real patient samples is required.
